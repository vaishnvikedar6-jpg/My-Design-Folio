## ♡ About the Folio

**My Design Folio** is my personal digital space for exploring the intersection of **UI/UX design, web development, visual storytelling, and emerging technology**.

This portfolio isn't just a collection of screens.

It's a record of how I think:

> **Understand the problem → explore the idea → design the experience → build the interaction → refine the details.**

I enjoy turning ideas into experiences that feel **intentional, intuitive, expressive, and human.**

# 💻 The Developer Side

I enjoy moving beyond static design and understanding **how the experience actually works underneath.**

```text
          ┌─────────────────────┐
          │      USER NEED      │
          └──────────┬──────────┘
                     ↓
          ┌─────────────────────┐
          │     UX / UI IDEA    │
          └──────────┬──────────┘
                     ↓
          ┌─────────────────────┐
          │     FRONTEND        │
          │  HTML • CSS • React │
          └──────────┬──────────┘
                     ↓
          ┌─────────────────────┐
          │      BACKEND        │
          │ Node • REST APIs    │
          └──────────┬──────────┘
                     ↓
          ┌─────────────────────┐
          │      DATABASE       │
          │  SQL • MongoDB      │
          └──────────┬──────────┘
                     ↓
          ┌─────────────────────┐
          │  COMPLETE PRODUCT   │
          └─────────────────────┘
```

> **I don't want to only design what users see.
> I want to understand what makes the experience work.**
